════════════════════════════════════════════════════════════════════
  简体中文 — 安装或手动替换 Polaris 后被拦下？按下面三步即可
════════════════════════════════════════════════════════════════════

macOS 可能提示以下两种之一：

  A.「"Polaris.app" 已损坏，无法打开。您应该将它移到废纸篓。」
  B.「无法打开 "Polaris.app"，因为无法验证开发者。」

两种都**不是**文件损坏，也不是病毒。原因是本应用没有使用付费的 Apple
开发者签名（Developer ID + 公证），macOS 对从网络下载的应用会加一个
「隔离属性」，未签名的应用就会被拦下。

──────────────────────────────────────────────────────────────
  三步解决
──────────────────────────────────────────────────────────────

  1. 先把左边的 Polaris 拖到右边的「应用程序 (Applications)」文件夹

  2. 打开「终端 (Terminal)」，粘贴下面这一行并回车：

         xattr -cr /Applications/Polaris.app

  3. 之后正常双击打开即可。每次从新下载的 DMG 手动安装或替换应用后，
     都需要执行一次；应用内更新会自己清理隔离属性，无需重复执行。

  ⚠️ 注意：对上面的提示 A（「已损坏」），「右键 → 打开」是**无效**的，
     必须用第 2 步的终端命令。提示 B（「无法验证开发者」）则可以用
     「右键 → 打开 → 确认」放行，也可以直接用第 2 步的命令。

  终端在哪：「访达 → 应用程序 → 实用工具 → 终端」，或按 Command+空格
  输入 Terminal 回车。


════════════════════════════════════════════════════════════════════
  English — Can't open Polaris after a manual install or replacement?
════════════════════════════════════════════════════════════════════

macOS may show one of these:

  A. "Polaris.app" is damaged and can't be opened. You should move it
     to the Trash.
  B. "Polaris.app" can't be opened because the developer cannot be
     verified.

Neither means the file is broken or malicious. This app is not signed
with a paid Apple Developer ID (no notarization), and macOS quarantines
anything downloaded from the internet.

  1. Drag Polaris into the Applications folder shown on the right.

  2. Open Terminal and run this single line:

         xattr -cr /Applications/Polaris.app

  3. Double-click to open as usual. Run the command once after each
     manual install or replacement from a newly downloaded DMG. In-app
     updates clear the quarantine attribute themselves.

  Note: for message A ("damaged"), right-click → Open does NOT help;
  the Terminal command is required. For message B, right-click → Open
  → confirm also works.

  Where is Terminal: Finder → Applications → Utilities → Terminal, or
  press Command+Space and type Terminal.

  繁體中文 — 安裝或手動替換 Polaris 後被擋下？按下面三步即可
════════════════════════════════════════════════════════════════════

macOS 可能提示以下兩種之一：

  A.「"Polaris.app" 已損毀，無法開啟。您應該將其移到垃圾桶。」
  B.「無法開啟 "Polaris.app"，因為無法驗證開發者。」

兩種都**不是**檔案損毀，也不是病毒。原因是本應用程式沒有使用付費的
Apple 開發者簽章（Developer ID + 公證），macOS 對從網路下載的應用程式
會加上「隔離屬性」，未簽章的應用程式就會被擋下。

──────────────────────────────────────────────────────────────
  三步解決
──────────────────────────────────────────────────────────────

  1. 先把左邊的 Polaris 拖到右邊的「應用程式 (Applications)」資料夾

  2. 開啟「終端機 (Terminal)」，貼上下面這一行並按 Enter：

         xattr -cr /Applications/Polaris.app

  3. 之後正常按兩下開啟即可。每次從新下載的 DMG 手動安裝或替換
     應用程式後都需執行一次；應用程式內更新會自行清除隔離屬性，
     無需重複執行。

  ⚠️ 注意：對上面的提示 A（「已損毀」），「按右鍵 → 打開」是**無效**的，
     必須用第 2 步的終端機指令。提示 B（「無法驗證開發者」）則可以用
     「按右鍵 → 打開 → 確認」放行，也可以直接用第 2 步的指令。

  終端機在哪：「Finder → 應用程式 → 工具程式 → 終端機」，或按
  Command+空白鍵輸入 Terminal 後按 Enter。

  Русский — Polaris не открывается после ручной установки или замены?
════════════════════════════════════════════════════════════════════

macOS может показать одно из двух сообщений:

  A. «Программу "Polaris.app" не удается открыть, так как она
     повреждена. Переместите ее в Корзину.»
  B. «Не удается открыть "Polaris.app", так как не удалось проверить
     разработчика.»

Ни одно из них не означает, что файл повреждён или вреден. Приложение
не подписано платным Apple Developer ID (без нотаризации), а macOS
помечает карантином всё, что скачано из интернета.

──────────────────────────────────────────────────────────────
  Решение в три шага
──────────────────────────────────────────────────────────────

  1. Перетащите Polaris слева в папку «Программы (Applications)»
     справа.

  2. Откройте «Терминал (Terminal)» и выполните одну строку:

         xattr -cr /Applications/Polaris.app

  3. Дальше открывайте двойным щелчком как обычно. Выполняйте команду
     один раз после каждой ручной установки или замены из заново
     скачанного DMG. Обновления внутри приложения сами снимают атрибут
     карантина.

  Внимание: при сообщении A («повреждена») способ «правый клик →
  Открыть» НЕ помогает, нужна команда из шага 2. При сообщении B
  «правый клик → Открыть → подтвердить» тоже работает.

  Где Терминал: Finder → Программы → Утилиты → Терминал, либо нажмите
  Command+Пробел и введите Terminal.


════════════════════════════════════════════════════════════════════
  فارسی — Polaris پس از نصب یا جایگزینی دستی باز نمی‌شود؟
════════════════════════════════════════════════════════════════════

macOS ممکن است یکی از این دو پیام را نشان دهد:

  A. «"Polaris.app" آسیب دیده است و باز نمی‌شود. آن را به سطل زباله
     منتقل کنید.»
  B. «"Polaris.app" باز نمی‌شود چون توسعه‌دهنده قابل تأیید نیست.»

هیچ‌کدام به معنای خراب بودن فایل یا وجود بدافزار نیست. این برنامه با
Apple Developer ID پولی امضا نشده است (بدون notarization) و macOS هر
چیزی را که از اینترنت دانلود شود قرنطینه می‌کند.

──────────────────────────────────────────────────────────────
  راه‌حل در سه گام
──────────────────────────────────────────────────────────────

  ۱. Polaris را از سمت چپ به پوشه «Applications» در سمت راست بکشید.

  ۲. «Terminal» را باز کنید و این یک خط را اجرا کنید:

         xattr -cr /Applications/Polaris.app

  ۳. سپس مانند همیشه با دوبار کلیک باز کنید. پس از هر نصب یا جایگزینی
     دستی از یک DMG تازه‌دانلودشده، این دستور را یک بار اجرا کنید.
     به‌روزرسانی‌های درون‌برنامه‌ای خودشان ویژگی قرنطینه را پاک می‌کنند.

  توجه: برای پیام A («آسیب دیده») گزینه «کلیک راست ← Open» کارساز
  نیست و حتماً باید فرمان گام ۲ را اجرا کنید. برای پیام B روش
  «کلیک راست ← Open ← تأیید» هم کار می‌کند.

  Terminal کجاست: Finder ← Applications ← Utilities ← Terminal، یا
  کلید Command+Space را بزنید و Terminal را تایپ کنید.
