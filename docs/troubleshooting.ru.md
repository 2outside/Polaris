## О неподписанных сборках (macOS / Windows)

Polaris **не подписывается сертификатом подписи кода**:

- **macOS**: сначала перетащите приложение в «Программы»; после каждой ручной установки или замены из заново скачанного DMG выполните
  `xattr -cr /Applications/Polaris.app`. Если система лишь сообщает, что не удалось проверить разработчика, можно вместо этого нажать правой кнопкой на приложении → «Открыть» → подтвердить.
  Эта команда рекурсивно очищает расширенные атрибуты бандла, поэтому выполняйте её только для доверенной сборки Polaris; сам механизм обновления очищает атрибут карантина автоматически.
  В DMG вложена та же инструкция по первому запуску на пяти языках (`README First.txt`) — когда Gatekeeper блокирует пользователя, тот не может попасть в приложение и мог вообще не видеть этот файл, поэтому та инструкция — единственное, что ему доступно в этот момент.
- **Windows**: SmartScreen «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае». Запросы UAC (установка helper / TUN) появляются как обычно — это лишь одно дополнительное подтверждение.

Подпись означала бы затраты на сертификат плюс модель доверия на основе манифеста подписи, конфликтующую с существующим самописным конвейером обновлений (оркестрация VBS / osascript / pkexec), поэтому от неё сознательно отказались (см. описание crate `updater`).

## Белый экран / артефакты отрисовки / повторяющиеся сбои процесса GPU

Чаще всего встречается на проприетарных драйверах NVIDIA, в виртуальных машинах (виртуальная видеокарта QEMU) и в удалённых рабочих столах (xrdp) — там, где нет нормального аппаратного ускорения. Композитор webview не выдаёт кадры, но **само прокси-ядро не затронуто** и продолжает работать и передавать трафик.

**Интерфейс ещё управляем** (изредка белый экран или артефакты; после переоткрытия окна интерфейс доступен) → Настройки → Отображение → «Графическая совместимость» → отключите «Аппаратное ускорение» → перезапустите Polaris. (На macOS этот блок не отображается: у WKWebView нет поддерживаемого переключателя отключения GPU.)

**Интерфейс не открывается вообще** (пустой экран с самого начала, до настроек не добраться) → оба способа ниже **не требуют участия интерфейса**:

### 1. Прямое редактирование config.json

Закройте Polaris, добавьте `"hardwareAcceleration": false` на верхнем уровне файла конфигурации и запустите снова:

| Платформа | Путь |
|---|---|
| Linux | `~/.config/com.polaris.app/polaris/config.json` |
| Windows | `%APPDATA%\com.polaris.app\polaris\config.json` |
| macOS | `~/Library/Application Support/com.polaris.app/polaris/config.json` |

```json
{
  "hardwareAcceleration": false
}
```

Чтение конфигурации намеренно сделано отказоустойчивым: повреждённый файл или неверный тип поля всегда откатываются к «включено по умолчанию», поэтому неправильное значение этого ключа не может сломать запуск (см. `src-tauri/src/graphics_compat.rs` — исходный текст читается напрямую до создания окна, без зависимости от успешной сборки store).

### 2. Переменные окружения платформы (разовая проверка без изменения конфигурации)

Эти переменные читаются **нативно** самими WebKitGTK / WebView2 и не требуют участия приложения. Polaris также намеренно не перезаписывает уже заданные вами одноимённые переменные, поэтому временный эксперимент во время диагностики не будет нарушен приложением.

```bash
# Linux (WebKitGTK) — DMABUF основное исправление белого экрана на NVIDIA, COMPOSITING закрывает сбои при resize
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 polaris
```

```powershell
# Windows (WebView2)
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--disable-gpu"; .\Polaris.exe
```

На macOS соответствующего переключателя нет (WKWebView не предоставляет публичного API, WebKit #26651 давно не реализован), поэтому `hardwareAcceleration` на macOS — это no-op: приложение честно пишет предупреждение в лог, а не заявляет, что настройка применена. Если вы столкнулись с белым экраном на macOS, откройте issue и приложите логи из
`~/Library/Application Support/com.polaris.app/polaris/logs/` (на Linux `~/.config/...`, на Windows `%APPDATA%\...`, каталог с тем же именем `logs/`).

> Оба переключателя — один и тот же ключ: `hardwareAcceleration` (прямая семантика, по умолчанию `true` = включено). Любое изменение вступает в силу только после **полного перезапуска приложения** — переменные окружения читаются лишь в момент создания webview.
